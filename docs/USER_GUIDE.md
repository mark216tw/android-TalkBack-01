# 使用指南

## 使用前準備

「說出來」支援 Android 8.0（API 26）以上。請先在手機的**系統文字轉語音設定**安裝並啟用中文離線語音；若要使用「中英文」模式，也請安裝英文離線語音。App 本身不要求網路權限，語音資料的取得、語音品質與可用語種由裝置上的 TTS 引擎決定。Android 13 以上建議允許通知，以查看背景朗讀控制。

## 朗讀分頁

1. 在「文章內容」貼上或輸入文章，或按「匯入 .txt 文字檔」。草稿會自動保存於本機。
2. 選擇朗讀語言：**中文**（預設，數字使用中文語音）或**中英文**（按字母／中文字片段切換離線語音）；拖動滑桿設定 0.5～1.5 倍語速。
3. 按主要按鈕開始朗讀；同一位置的按鈕會依狀態顯示「朗讀」、「暫停」或「繼續」。也可按「停止」。暫停後續讀會重唸目前的語音片段。
4. 在朗讀中設定 15、30 或 60 分鐘睡眠計時器，或按「取消計時」。倒數到期時會唸完**目前句子**才停止；如果已暫停，則直接停止並記住目前句子。關閉 App 畫面或鎖定螢幕時，前景服務會繼續朗讀，通知可用來暫停、續讀與停止。
5. 「從上次進度繼續」恢復單篇文章的句子位置。若以文章庫「儲存為新文章」，會新增一篇；開啟已存文章後改標題或內容，按「儲存修改」才會覆寫該篇。

### 從其他 App 分享文字

在支援分享純文字的 App 中選擇「分享」→「說出來」。分享內容會**取代**現有草稿，不會自動新增到文章庫；有需要時再按「儲存為新文章」。分享時若正在朗讀，原本的朗讀會停止。

### 匯入 `.txt`

按「匯入 .txt 文字檔」，以 Android 系統檔案選擇器挑選 `.txt`（副檔名不區分大小寫）。檔案須為 **UTF-8（可含 BOM）**、非空白且不超過 **2 MB**。系統會顯示檔名、字數及前 2,500 字預覽：

- 按「確認匯入」：取代文章內容並保存為草稿；之後可朗讀或手動存入文章庫。
- 按「取消」或關閉預覽：原草稿不變。
- 若副檔名、大小或編碼不符：顯示錯誤，原草稿不變。

透過系統選擇器取得單一檔案的讀取權限，不需要裝置儲存空間權限。

## 逐句分頁

- 一般朗讀時顯示目前輸入的文章；播放清單執行時顯示當前播放的文章。點選任何句子即可從該句開始，朗讀中亦可使用「上一句／下一句」。
- 以底色和邊框標示目前句子。可選「小字／中字／大字」，字體設定會保留在本機。
- 預設自動跟隨目前句子；手動拖曳列表後會暫停跟隨，以免閱讀的位置被拉走。按「回到目前句（恢復自動跟隨）」即可返回。切換分頁不會中斷播放。
- 句子以常見中英文句號、問號、驚嘆號、分號及換行分段；小數點與英文大寫縮寫的內部句點會盡量保留在同一句。非常規標點可能由 TTS 引擎自行決定停頓。

## 文章庫分頁

輸入關鍵字即可比對已儲存文章的標題和內文。按「開啟／編輯」會返回朗讀頁；改標題或內文後，按「儲存修改」覆寫同一篇。按「儲存為新文章」則保留原篇並另建新篇。按「刪除」會移除該篇及其播放清單項目；刪除前請確認內容已不需要。

## 播放清單分頁

先在文章庫儲存文章，再於播放清單分頁逐篇按「加入」。清單中的「上移／下移」可調整順序，「移除」只會移出播放清單，不會刪除文章庫原文。按「從第一篇開始」依順序連續朗讀；停止或睡眠計時到期後，可按「續聽」從記錄的**文章與句子**恢復。單篇文章與播放清單各自保有續讀進度。

## 常見問題

| 情況 | 建議處理 |
| --- | --- |
| 找不到中文或英文離線語音 | 到系統 TTS 設定下載相應語音資料並重新開啟 App；英文語音僅中英文混讀時需要。 |
| 數字或中英文交界處發音不理想 | 試著換用中文／中英文模式，或在文章中加入空格與標點；發音也取決於手機語音引擎。 |
| 匯入檔案失敗 | 檢查 `.txt` 副檔名、UTF-8 編碼、2 MB 大小上限與檔案是否有文字。 |
| 按暫停後從句首或片段開頭重讀 | Android TTS 沒有跨語音引擎一致的精準暫停位置；續讀時重唸中斷片段是目前的設計。 |
| 背景播放看不到通知控制 | Android 13 以上檢查通知權限與系統通知設定。 |
