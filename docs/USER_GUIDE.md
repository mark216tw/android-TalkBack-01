# 使用指南

## 使用前準備

「mini說書」支援 Android 8.0（API 26）以上。請先在手機的**系統文字轉語音設定**安裝並啟用中文離線語音；若要使用「中英文」模式，也請安裝英文離線語音。App 本身不要求網路權限，語音資料的取得、語音品質與可用語種由裝置上的 TTS 引擎決定。Android 13 以上建議允許通知，以查看背景朗讀控制。

## 朗讀分頁

1. 在「文章內容」貼上或輸入文章，草稿會自動保存於本機；TXT 匯入請到文章庫右上角操作。
2. 朗讀頁保留內容、儲存新文章、單篇續讀與設定入口。語言、語速、播放控制及朗讀狀態集中在逐句頁。
3. 開始後可切到逐句頁暫停／繼續、跳句或停止。暫停後續讀會重唸目前的語音片段。
4. 下方導覽列的「朗讀」按鈕：在其他頁面點擊會切換到朗讀頁；在朗讀頁點擊會開始朗讀，再點擊「停止」會停止（暫停中也會停止），之後可再次開始朗讀。
5. 「從上次進度繼續」恢復單篇文章的句子位置。在朗讀頁按「儲存為新文章」，先確認標題後才新增文章；預設標題取第一個非空白行的前 35 字，標題不得為空白。修改已儲存文章請在文章庫點擊鉛筆圖示。

## 設定

點擊朗讀頁「朗讀」標題右側的齒輪進入設定，其餘分頁不顯示齒輪或獨立頂部列。使用 Android 返回鍵／返回手勢或設定頁返回箭頭會回到主畫面的朗讀頁。

- **顯示模式**：系統（預設）、淺色、深色，立即生效；系統模式會跟隨手機設定。狀態欄與系統導覽列的外觀及圖示明暗同步調整。
- **主題色彩**：活力珊瑚、陽光橘、薄荷綠、晴空藍、葡萄紫、莓果粉，以兩列、每列三個選項呈現，色塊與名稱整合在同一個按鈕內。下方提供單一 Hue 彩色滑桿，左邊的小圓形色塊呈現目前自訂色彩；預設色、滑桿與色塊相互連動，調整立即生效。顯示模式與色相會保存在本機。
- **逐句朗讀字型大小**：小字（18 sp）、中字（22 sp）、大字（28 sp），立即套用逐句頁並保存在本機。
- 已選的設定、朗讀語言與逐句字體大小以實心主色、高對比粗體文字及勾選圖示標示。
- **睡眠計時器**：在朗讀或暫停中設定 15、30 或 60 分鐘，剩餘時間同一列右側提供「取消」。到期時唸完**目前句子**才停止；等待句尾時也可按提示同列的「取消」撤銷停止。暫停中到期則直接停止並記住目前句子。關閉 App 畫面或鎖定螢幕時，前景服務會繼續朗讀，通知可用來暫停、續讀與停止。

### 從其他 App 分享文字

在支援分享純文字的 App 中選擇「分享」→「mini說書」。分享內容會**取代**現有草稿，不會自動新增到文章庫；有需要時再按「儲存為新文章」。分享時若正在朗讀，原本的朗讀會停止。

### 匯入 `.txt`

在文章庫右上角按匯入圖示，以 Android 系統檔案選擇器挑選 `.txt`（副檔名不區分大小寫）。檔案須為 **UTF-8（可含 BOM）**、非空白且不超過 **2 MB**。完整內容帶入文章表單，輸入標題並儲存後建立新文章；取消或匯入失敗不建立文章、不更動朗讀草稿。

透過系統選擇器取得單一檔案的讀取權限，不需要裝置儲存空間權限。

## 逐句分頁

- 上方同列提供中文／中英文選項與語速下拉選單，語速可選 0.5～1.5 倍（每次增加 0.1 倍），已選倍速以主色、粗體與勾選標示，設定保存在本機。播放中修改語速會從下一個語音片段生效；切換語言會從目前句重唸，保留播放／暫停狀態、播放清單及計時器。後續清單文章使用新設定，缺少英文離線語音時會提示並保留原設定。
- 播放控制固定同列由左至右為「上一句、下一句、朗讀／暫停／繼續、停止」，尚未播放時停止按鈕停用。一般文章不顯示「目前輸入的文章」文字；播放清單中保留目前文章標題。
- 一般朗讀時顯示目前輸入的文章；播放清單執行時顯示當前播放的文章。點選任何句子即可從該句開始，朗讀中亦可使用「上一句／下一句」。
- 以底色和邊框標示目前句子。字型大小請到朗讀頁齒輪的設定內選「小字／中字／大字」，設定會保留在本機；朗讀頁不另外顯示目前句子。
- 預設自動跟隨目前句子；手動拖曳列表後暫停跟隨，自動讀到下一句或按「下一句」時會恢復跟隨並捲到目前句子。切換分頁不會中斷播放。
- 句子以常見中英文句號、問號、驚嘆號、分號及換行分段；小數點與英文大寫縮寫的內部句點會盡量保留在同一句。非常規標點可能由 TTS 引擎自行決定停頓。

## 文章庫分頁

輸入關鍵字即可比對已儲存文章的標題和內文。標題放大為 20 sp，標題前保留一般文章圖示，不顯示播放中／暫停圖示。播放狀態以文章 ID 辨識，集中在可操作的播放按鈕上，即使兩篇內文相同也不會誤認。

每篇標題下方的操作圖示同列靠右，以 40 dp 圓形與 20 dp 圖示呈現，保留 48 dp 點擊範圍：播放按鈕為主色實心圓，編輯（鉛筆）、加入清單、刪除（垃圾桶）為描邊。未播放文章顯示三角形，點擊從第一句開始並切到逐句頁；目前播放文章顯示暫停圖示，可直接暫停，暫停後三角形可繼續，這兩種操作留在目前頁。編輯在文章庫表單完成，標題與內容皆必填；儲存更新原篇，取消不修改，也不取代草稿。編輯播放中文章不會中斷本次內容，修改供下次播放使用。加入清單只對未加入文章顯示。刪除須確認，確認後移除文章及清單項目。

### 新增與匯入文章

- 右上角 **＋**：開啟新增文章表單，填入標題與內容後按「儲存」。兩個欄位皆必填，僅空白字元不算有效內容。
- 右上角 **匯入圖示**：選擇 UTF-8 `.txt`（可含 BOM、非空白、不超過 2 MB），系統會將完整內容帶入文章表單。輸入標題後按「儲存」建立新文章，也可先編輯內容。
- 取消表單或返回不建立文章。新增及匯入不會取代朗讀頁草稿，也不會中斷正在播放的文章；儲存後顯示文章庫並清除搜尋，方便找到新文章。

## 播放清單分頁

操作圖示採用圓形按鈕：播放為主色實心圓，其餘為圓形描邊；停用的上移／下移會淡化顯示。

文章由文章庫的加入清單圖示加入；播放清單沒有加入文章區塊。每篇放大標題下方同列靠右顯示播放切換、上移、下移、移除（叉號），標題前不顯示播放狀態圖示。播放／暫停／繼續的操作與文章庫一致，清單換篇時按鈕同步更新。第一篇上方依序顯示清單說明、目前播放描述與可用的續聽按鈕。上移／下移調整順序，移除只移出清單、不刪除文章庫原文。開始播放會切到逐句頁，再接續後面的文章；要播放整份清單，按第一篇播放即可。停止或計時到期後，可按「續聽」從記錄的文章與句子恢復。

## 常見問題

| 情況 | 建議處理 |
| --- | --- |
| 找不到中文或英文離線語音 | 到系統 TTS 設定下載相應語音資料並重新開啟 App；英文語音僅中英文混讀時需要。 |
| 數字或中英文交界處發音不理想 | 試著換用中文／中英文模式，或在文章中加入空格與標點；發音也取決於手機語音引擎。 |
| 匯入檔案失敗 | 檢查 `.txt` 副檔名、UTF-8 編碼、2 MB 大小上限與檔案是否有文字。 |
| 按暫停後從句首或片段開頭重讀 | Android TTS 沒有跨語音引擎一致的精準暫停位置；續讀時重唸中斷片段是目前的設計。 |
| 背景播放看不到通知控制 | Android 13 以上檢查通知權限與系統通知設定。 |
