# 系統設計文件

## 目的與範圍

本系統讓使用者以裝置內建的離線 TTS 聆聽自己的文章。核心流程是「取得文字 → 選語言與語速 → 朗讀／逐句定位 → 保存文章及續聽」；另支援背景播放、多篇連播與睡眠計時。不依賴帳號、伺服器或雲端語音。

## 功能需求

| 編號 | 需求 | 實作行為 |
| --- | --- | --- |
| F01 | 取得文字 | 輸入／貼上、接收 `text/plain` 分享、預覽後匯入 UTF-8 `.txt`。分享與確認匯入會取代草稿。 |
| F02 | 離線朗讀 | 中文模式預設；中英文模式依片段切換已安裝的離線語音。調整 0.5～1.5 倍語速。 |
| F03 | 控制播放 | 朗讀／暫停／繼續／停止、跳到指定句、上一句／下一句。背景通知提供基本播放控制。 |
| F04 | 視覺定位 | 四個底部分頁；逐句分頁標示目前句、小／中／大字，手動捲動可停止自動跟隨。 |
| F05 | 管理文章 | 草稿自動保存；文章庫可新增、編輯、更名、搜尋、刪除。 |
| F06 | 多篇連播 | 播放清單以文章 ID 挑選和排序；完成一篇後接續下一篇，停止後可從文章及句子續聽。 |
| F07 | 睡眠計時 | 15／30／60 分鐘；時間到時等目前句所有 TTS 片段完成再停止，保存下一句或下一篇位置；暫停中則直接停止。 |

## 非功能需求與限制

- **離線與隱私**：不宣告網路權限；文章、清單與進度只儲存在裝置的 App 私有資料中。語音可用性取決於系統安裝的離線語音資料。
- **可理解的回饋**：TTS 初始化與缺少離線語音時顯示文字提示；匯入錯誤不覆寫草稿；朗讀進度顯示句子索引與目前內容。
- **長文安全**：TTS utterance 最長約 700 字元；從 Activity 啟動單篇朗讀時，Service 從本機草稿讀取文章而不是把長文放入 Intent。`.txt` 匯入上限 2 MB，預覽顯示前 2,500 字。
- **平台界線**：最低 Android API 26。Android TTS 缺乏一致的精確暫停 API，續讀可能重唸目前語音片段；發音與停頓受裝置語音引擎影響。

## 朗讀狀態機

| 狀態 | 觸發事件 | 結果 |
| --- | --- | --- |
| `LOADING` | TTS 初始化成功／失敗 | 進入 `READY`；或顯示錯誤並進入 `ERROR`。 |
| `READY` | 單篇／清單開始或點選句子 | 建立句子與語音片段，進入 `PLAYING`。 |
| `PLAYING` | TTS 片段完成 | 同句送下一片段；句末更新位置；文章結束時清單接下一篇或回到 `READY`。 |
| `PLAYING` | 暫停／停止／跳句 | 暫停進入 `PAUSED`；停止回到 `READY`；跳句中止舊語音並從目標句開始。 |
| `PAUSED` | 繼續／停止／跳句 | 繼續進入 `PLAYING` 並重唸中斷片段；停止回到 `READY`；跳句更新目標位置。 |
| `PLAYING` | 睡眠計時到期 | 設定句尾停止旗標，同一句剩餘片段完成後回到 `READY` 並儲存下次位置。 |
| `PAUSED` | 睡眠計時到期 | 立即停止，保留目前句。 |

朗讀器以 utterance ID 和 generation 驗證回呼，防止舊的 TTS 完成事件在暫停、跳句或停止後推進新文章。

## 資料設計

| 實體 | 主要欄位 | 說明 |
| --- | --- | --- |
| `SavedArticle` | `id`, `title`, `text` | UUID 不因改標題／內文改變；文章庫 JSON 陣列保存於 `saved`。 |
| `ReadingSentence` | `text`, `start`, `end` | 指向文章原文範圍；畫面呈現使用原文。 |
| `ReadingSegment` | `text`, `language`, `sentenceIndex` | 一句可能拆成數個中英 TTS 片段；計時器須以句界線判斷。 |
| `ReadingBookmark` | `text`, `position`, `speed`, `mode` | 單篇續讀位置，以句子索引保存。 |
| `PlaylistProgress` | `articleId`, `sentence`, `speed`, `mode` | 清單續讀位置；文章 ID 對應已儲存文章。 |
| `playlist` | 已儲存文章 ID 的有序陣列 | 清單調整順序只更動 ID，不複製文章內容。 |

如果使用者刪除文章，該文章同時從播放清單移除。匯入與分享僅更新草稿，按「儲存為新文章」才會建立 `SavedArticle`。

## 介面設計

- **朗讀**：文章輸入、語言／語速、主播放按鈕、單篇續讀、睡眠計時與 `.txt` 匯入。
- **逐句**：全頁句子列表、字體大小、播放／跳句操作；標示目前句；手動拖曳後顯示「回到目前句」。播放清單中呈現當前篇，一般朗讀時呈現草稿。
- **文章庫**：搜尋已存文章、開啟編輯、刪除；編輯後在朗讀頁明確按「儲存修改」。
- **播放清單**：加入／移除已存文章、上下調整順序、從首篇開始與從上次位置續聽。

## 例外與邊界情況

- 無中文離線語音時無法開始朗讀；中英文模式遇到英文而缺少英文離線語音時提示安裝。App 不會刻意選用標示需要網路的語音。
- 匯入非 `.txt`、超過大小限制、空白或非有效 UTF-8 時，只顯示錯誤，不更動原草稿。
- 文章庫已刪除或內容空白的播放清單項目會被跳過；整個清單讀完後移除清單進度。
- 計時器依服務存活的單調時鐘運作；行程遭系統終止時朗讀與當次計時一同停止，已保存的閱讀位置可供下次續聽。
- 目前以標點／換行切句並對常見日期、幣別、百分比、英文縮寫進行有限規則處理；非標準格式可能仍依 TTS 引擎發音。

## 驗收情境

1. 輸入「我有 3 本書」採中文模式朗讀，數字不切換到英文離線語音；中英文模式可朗讀中英混用文字。
2. 在逐句頁點選句子、暫停、續讀與切換分頁，文章及句子定位維持一致；手動捲動後不再自動跳走，點「回到目前句」可恢復。
3. 從其他 App 分享純文字會取代草稿；匯入 UTF-8（含 BOM）`.txt` 需先預覽確認，取消／失敗後草稿不變。
4. 加入至少兩篇文章到播放清單，第一篇結束後自動播放第二篇；中途停止與重新開啟 App 後可從記錄的文章與句子續聽。
5. 睡眠計時在中英文混用的一句中到期，不會停在該句中間；唸完整句後保存下一句。暫停時到期則立即停止。
