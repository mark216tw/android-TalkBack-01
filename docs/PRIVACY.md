# 隱私與資料

「說出來」以離線處理為設計目標。App 不建立帳號、不要求網路權限、不串接雲端 TTS，也沒有程式碼將使用者文章傳送至伺服器。

## 儲存於裝置上的資料

- 輸入／分享／確認匯入後的文章草稿。
- 使用者主動儲存的文章標題與內文，以及播放清單文章 ID／順序。
- 單篇與播放清單的續讀位置、語言、語速與逐句字體設定。

以上資料由 Android App 私有 `SharedPreferences` 保存；不對其他 App 開放資料檔案。系統檔案選擇器僅提供使用者選定檔案的讀取權限，匯入需再次確認才會取代草稿。Android TTS 引擎由裝置及使用者的系統設定提供；請選擇並安裝離線語音，語音引擎自身行為以其供應者說明為準。

## 權限

| 權限／能力 | 用途 |
| --- | --- |
| `FOREGROUND_SERVICE`、`FOREGROUND_SERVICE_MEDIA_PLAYBACK` | 畫面切換或鎖定時維持正在進行的朗讀，並顯示前景通知。 |
| `POST_NOTIFICATIONS` | Android 13+ 顯示背景朗讀通知及控制。 |
| `ACTION_OPEN_DOCUMENT` | 使用 Android 系統檔案選擇器讀取使用者挑選的 `.txt`，不需儲存空間權限。 |

Manifest **不宣告** `INTERNET` 權限。

## 刪除資料

文章庫可逐篇刪除文章；刪除文章時也會移除其播放清單項目。草稿與其餘設定位於 App 私有儲存空間，可透過 Android「設定 → 應用程式 → 說出來 → 儲存空間 → 清除資料」一併清除；清除後無法由本 App 還原。App 的 `allowBackup` 設為 `false`，不透過 Android 備份機制自動備份這些資料。
